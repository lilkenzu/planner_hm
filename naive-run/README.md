# Наивный прогон (для сравнения)

Результат одного короткого промпта без спеки и без правил проекта — сделан
для сравнения с итоговой реализацией в корне репозитория. Код здесь **не
дорабатывается и не поддерживается**: это снимок «как получилось сразу»,
а не альтернативная версия продукта.

Разбор отличий и найденный в этом варианте баг (переход на летнее время
обрабатывается некорректно) — в [`../sessions/audit.md`](../sessions/audit.md)
и в основном [`../README.md`](../README.md) → «Наивный прогон и сравнение».

Запуск (если нужно посмотреть вживую): `python3 -m http.server 8766` в этой
папке, затем `http://localhost:8766`.
