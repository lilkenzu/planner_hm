## Известные проблемы

- Валидация «начало рабочего дня раньше окончания» добавлена в шаге 1 по
  собственному решению агента (не обсуждалась явно в SPEC.md/вопросах) —
  необходима для корректности будущего расчёта доступности, но формально это
  самостоятельное решение, а не пункт спеки. Зафиксировано в `session-1.md`.
- SSH-ключ для push сгенерирован без пароля — осознанный компромисс ради
  неинтерактивного push агентом, но снижает защиту ключа при краже файла.
  Приемлемо для учебного репозитория, но не для боевого проекта. См. `TOOLS.md`.
- Первый состав участников для проверки 33/67/100% (Нью-Йорк+Катманду+Токио)
  оказался нерабочим — Нью-Йорк и Токио физически не пересекаются по времени
  ни при каком раскладе. Заменён на Катманду/Берлин/Лондон. Не баг, а факт о
  часовых поясах — оставлено в журнале как есть.
- Для Катманду подписи ячеек всегда будут на «:15»/«:45», а не на «:00»/«:30»,
  как у остальных — неустранимое следствие сдвига +5:45, не баг.
